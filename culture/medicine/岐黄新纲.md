# 一、阴阳五行学说

> 阴阳五行是描述**关系**的学说：相生=相互促进，相克=相互制约；本质特征非肃杀/孕育，而是**牵制的平衡**。

## 1.1 阴阳总纲

- 阴阳失衡 → 正邪相争 → 祛邪扶正
- **清阳出上窍，浊阴出下窍；清阳发腠理，浊阴走五脏；清阳实四肢，浊阴归六腑。**
- 阴中之阳 / 阳中之阴：见 [二、脏腑阴阳](#二气血津液与脏腑)

## 1.2 四气五味与中药

- **四气**：温、热、寒、凉
- **五味**：酸、苦、甘、辛、咸
- **组方思路**：主料（君）+ 配菜（臣）+ 调料（佐）+ 提味（使）

### 君臣佐使

- **君药**：主攻，针对主症，用量最大
- **臣药**：辅助，增强君药之效
- **佐药**：协助或制约（降毒、兼顾兼证）
- **使药**：引经，引导药力达病所

### 五味详解

- **酸味** ｜ 归肝、胆经 ｜ 收敛、固涩 ｜ 如乌梅、五味子
- **苦味** ｜ 归心、小肠经 ｜ 清热、泻火、燥湿、通便 ｜ 如黄连、大黄
- **甘味** ｜ 归脾、胃经 ｜ 补益、和中、缓急 ｜ 如甘草、大枣
- **辛味** ｜ 归肺、大肠经 ｜ 发散、行气、活血 ｜ 如生姜、薄荷
- **咸味** ｜ 归肾、膀胱经 ｜ 软坚散结、泻下通便 ｜ 如海藻、芒硝

## 1.3 五行生克

> 相生（促进）、相克（制约）。**子盗母气、母病及子；虚则补母、实则泻子。**

### 五行本象

```
木：生长、舒展（如树木）　　火：炎热、升腾（如火焰）
土：承载、生化（如大地）　　金：肃杀、收敛（如金属）
水：寒凉、流动（如江河）
```

### 相生（循环促进）

```
木生火：木燃生火　　火生土：火尽成灰（土）
土生金：土藏矿金　　金生水：金熔为液 / 金面凝露
水生木：水润草木
口诀：木 → 火 → 土 → 金 → 水 → 木（循环相生）
```

### 相克

```
木克土：根破土　　土克水：堤拦洪
水克火：水灭火　　火克金：火熔金
金克木：刀斧伐木
```

### 相侮（反克）

```
木侮金（肝火犯肺）　　火侮水（心火下汲肾阴）
土侮木（脾湿困肝）　　金侮火（肺虚火旺）
水侮土（肾水泛脾）
```

## 1.4 五行对应五脏

```
木 → 肝（主疏泄）　　火 → 心（主血脉）
土 → 脾（主运化）　　金 → 肺（主呼吸）
水 → 肾（主藏精）
```

### 相生（促进关系）

- 木生火：肝好 → 心好（肝血足则心血充）
- 火生土：心好 → 脾好（心阳温脾助化）
- 土生金：脾好 → 肺好（脾运营养润肺）
- 金生水：肺好 → 肾好（肺降助肾纳气）
- 水生木：肾好 → 肝好（肾精养肝血）

### 相克（制约关系）

- 木克土：肝旺 → 伤脾（肝郁脾虚）
- 土克水：脾虚 → 肾泛（脾不运湿，肾水泛滥）
- 水克火：肾虚 → 心亢（水不制火）
- 火克金：心亢 → 伤肺（火灼肺阴）
- 金克木：肺虚 → 肝亢（金不制木）

## 1.5 五行象属（天干地支）

### 天干化五行

```

甲、乙属木（肝与胆）　　丙、丁属火（心与小肠）
戊、己属土（脾与胃）　　庚、辛属金（肺与大肠）
壬、癸属水（肾与膀胱）

### 天干阴阳象（十干本象）

- **甲木（阳）**：参天大树、春雷、生机勃发
- **乙木（阴）**：藤蔓花草、微风拂林、滋养调和
- **丙火（阳）**：烈日火山、能量释放
- **丁火（阴）**：烛光炉火、持久内敛
- **戊土（阳）**：高山城墙、稳固承载
- **己土（阴）**：田园湿土、孕育化育
- **庚金（阳）**：刀剑秋霜、破旧立新
- **辛金（阴）**：珠玉秋露、精致润泽
- **壬水（阳）**：江河奔流、洗涤更新
- **癸水（阴）**：雨露井泉、潜藏静谧

### 地支与季节

```
木：寅、卯（春）　　火：巳、午（夏）
土：辰、未、戌、丑（四季末月）　　金：申、酉（秋）　　水：亥、子（冬）
```

- 春（寅卯辰）：惊蛰阳气动 → 春雨生机 → 雷雨万物长
- 夏（巳午未）：地气升 → 极阳极热 → 土燥果熟
- 秋（申酉戌）：肃杀凝露 → 寒霜凋零 → 风劲归藏
- 冬（亥子丑）：阴雨潜藏 → 寒冰极阴 → 冻土孕春

## 1.6 五行系统对应关系详解

### 一、时空方位系统

- 五方：东（木）— 南（火）— 中（土）— 西（金）— 北（水）
- 五季：春（木）— 夏（火）— 长夏（土）— 秋（金）— 冬（水）
- 天干：甲乙（木）— 丙丁（火）— 戊己（土）— 庚辛（金）— 壬癸（水）
- 地支：寅卯（木）— 巳午（火）— 辰戌丑未（土）— 申酉（金）— 亥子（水）
- 时辰：3–7 时（木）— 7–11 时（火）— 11–19 时（土）— 19–23 时（金）— 23–3 时（水）

### 二、自然现象系统

- 五气：风（木）— 暑热（火）— 湿（土）— 燥（金）— 寒（水）
- 五化：生（木）— 长（火）— 化（土）— 收（金）— 藏（水）
- 五星：岁星（木）— 荧惑（火）— 镇星（土）— 太白（金）— 辰星（水）
- 神兽：木青龙、火朱雀、土（中宫）、金白虎、水玄武

### 三、人体生理系统

**五脏系统**

- **肝（木）**：藏血、主筋、开窍于目
  - 疏泄不及：无汗、尿少、粪难、腹痛、胁痛、经迟
  - 疏泄太过：自汗、尿多、遗精、发热、头晕、耳鸣、白带、经早
- **心（火）**：主血脉、藏神、开窍于舌
  - 宣通不及：血痹、神倦、口淡、血寒
  - 宣通太过：舌痛、喉痛、心跳、心烦
- **脾（土）**：主运化、统血、开窍于口
  - 运化不及：腹满、停食、吐泻、四肢不举、倦怠（土气填实则不化）
- **肺（金）**：主气、司呼吸、开窍于鼻
  - 收敛不及：汗多、头晕、发热、咳逆、遗泄、痿软
  - 收敛太过：恶寒、粪艰、胸闷、无汗
- **肾（水）**：藏精、主骨、开窍于耳及二阴
  - 封藏不及：阳越、头晕、发热、足肿（肾水愈封藏，阳根愈固）

**三焦**：相火燔灼不及则下寒、肾寒、二便不固；相火降于水中则生元气，不降则外热内寒。

**五腑对应**：胆（木）— 小肠（火）— 胃（土）— 大肠（金）— 膀胱（水）

# 二、气血津液与脏腑

> 用气血运行理解五脏：气血包含激素（如肾上腺素）、血液、津液。

## 2.1 脏腑阴阳

```
五脏为阴：
  肝 阴中之阳（升发疏泄）　　心 阳中之阳（火最热）
  脾 阴中之至阴（运化居中）　肺 阳中之阴（居阳主肃降）
  肾 阴中之阴（藏精最寒）　　胆 阳中之少阳（兼具阴阳）

六腑为阳：
  小肠 阳中之阳（火最热）　　胃 阳中之阴（阴润主降）
  大肠 阳中之阴（传导属金）　膀胱 阳中之阴（主水液）
  三焦 阳中之阳（通行元气）
```

## 2.2 营卫之气

> 谷入胃，气传与肺；清者为营，浊者为卫；**营行脉中，卫行脉外**。

## 2.3 气血津液辨证

- 气虚、气陷、气滞、气逆
- 津液失常：不足则燥，停聚则痰饮水肿

# 三、病因病机

- 阴阳失衡，正邪相争
- 六淫相侵，七情过激
- 饮食失节，劳逸失度
- 气血失和，脏腑失衡
- 痰湿瘀毒，阴阳乖离

**外感内伤**

- 六淫：风、寒、暑、湿、燥、火
- 七情：喜、怒、忧、思、悲、恐、惊

> **虚实总纲**：邪气盛则实，精气夺则虚。
> 有余者肿、痛曰实；不足者痒、麻曰虚。
> 久病为虚，攻邪扶正；初实久虚。
> 虚则补之、陷则灸之；实则泻之、陈则除之；不胜不虚以经取之。

# 四、诊断方法

> 望闻问切，神圣工巧。汗吐下和、温清消补。

## 4.1 舌诊

> 脾胃为主；舌如人体：舌根肾、左肝右胆、中脾胃、尖心肺。

**形态**

- 胖大：脾肾阳虚 ｜ 瘦薄：阴血亏虚 ｜ 裂纹：津血亏虚
- 芒刺：内热过剩 ｜ 舌光：阴液衰竭 ｜ 齿痕：脾虚湿盛

**颜色**

- 边红：肝气郁结 ｜ 青紫：血瘀 ｜ 苔腻：湿重
- 舌黄：热 ｜ 灰黑：寒 ｜ 淡白：气血亏虚 ｜ 绛舌：里热亢盛、阴虚火旺

**动态**

- 舌软：气血亏虚 ｜ 舌硬：内热伤津、风痰 ｜ 舌斜：中风 ｜ 舌短：可热可寒

**舌下脉络**：粗为瘀滞，细为虚亏。

## 4.2 脉诊

> 脉诊定乾坤。

**经典原文**

> 夫脉者，血之府也。长则气治，短则气病，数则烦心，大则病进。上盛则气高，下盛则气胀。代则气衰，细则气少，涩则心痛。浑浑革至如涌泉，病进而危；绵绵其去如弦绝，死。

**寸关尺分候**

- 诊法：寸口、人迎、趺阳、太溪（如吹笛，响处不同）
- 左手：寸心、关肝、尺肾 ｜ 右手：寸肺、关脾、尺命门
- 三焦：上中下 ｜ 寸为阳、尺为阴

**常见脉象**：浮、沉、迟、数、滑、涩、弦、细、代、结、促等（详见后世脉学专书，此处仅录《素问》原文纲领）。

## 4.3 十问歌

```
一问寒热二问汗，三问头身四问便；
五问饮食六胸腹，七聋八渴俱当辨；

再添片语告儿科，麻痘惊疳全占验。

# 五、辨证体系

## 5.1 八纲辨证

```
阴、阳 —— 类别（总纲）
表、里 —— 位置（病位）
寒、热 —— 性质（病性）
虚、实 —— 邪正（病态）
```

- 初实久虚；虚则补之、实则泻之。

## 5.2 气血津液辨证

- 气虚、气陷、气滞、气逆；血虚、血瘀、血热；津液不足、水湿停聚。

## 5.3 脏腑辨证

- 单独脏病、单独腑病、脏腑兼病。

**开窍对应**：心舌、脾口、肺鼻、肝目、肾耳。

## 5.4 六经辨证

少阳（枢）  足胆·手三焦    胁肋　　　　　半表半里，三阳枢纽

## 5.5 卫气营血辨证

- 卫 → 气 → 营 → 血（温热病深浅传变）

# 七、针灸疗法

## 7.1 经络系统

> 阳经向下、阴经向上；双手举起，阴升阳降。

**十二经体表分布口诀**

```

旁开中线半二四（腹：肾胃脾）
督旁寸半与三寸（膀胱一二）
```

## 7.2 穴位分类

- 阳脉有原穴 ｜ 井穴治脏病 ｜ 荥穴取色 ｜ 输穴取时 ｜ 经穴取声 ｜ 合穴取胀满

### 五输穴（井荥输经合）

> 所出为井，所溜为荥，所注为输，所行为经，所入为合；二十七气所行，皆在五输。

```
阴经：井木、荥火、输土、经金、合水
阳经：井金、荥水、输木、经火、合土
井荥输经合 ↔ 冬春夏长秋
```

- 井：四肢末端，泻热开窍 ｜ 荥：指关节，主湿热
- 输：掌指关节，主关节疼痛 ｜ 经：腕踝上，主喘咳痰热
- 合：肘膝附近，主脏腑之症
- 井主心下满，荥主身热，输主体重节痛，经主咳喘寒热，合主逆气而泄
- 手不过肘、足不过膝；泻井当泻荥，补井当补合

### 原穴

- 脏腑原气经过留止处；十二经在腕踝关节附近各一原穴。

### 络穴

- 十五络脉别出处；沟通表里、治表病及里/里病及表。

### 郄穴

- 各经经气深聚处；十二经 + 阴维阳维阴蹻阳蹻共 16 穴，多治急性病（除梁丘外皆在肘膝下）。

### 八会穴

```
脏会章门　　腑会中脘　　筋会阳陵泉　　髓会绝骨（悬钟）
血会膈俞　　骨会大杼　　脉会太渊　　　气会膻中
```

> 募在阴、俞在阳；阴病行阳、阳病行阴；五脏刺背、六腑刺胸。

### 特定穴总括

- 人体有病，多在这些腧穴出现病理反应；背俞穴属膀胱经，多主脏病。

## 7.6 针灸基础知识

**针具规格**

```
直径：0.25 / 0.30 / 0.35 / 0.40 mm
号数：32 / 30 / 28 / 26
长度：25mm(1寸) 40mm(1.5寸) 50mm(2寸) 60mm(2.5寸) 75mm(3寸)
1寸 ≈ 1.5 cm
```

**取穴方法**

- 中指同身寸：中指中节为一寸
- 拇指同身寸：拇指宽为一寸
- 横指同身寸：四指并拢三寸，剑指宽 1.5 寸
- 骨度分寸法

**操作**：由内到外环形消毒。

## 7.7 针法技术

- 基本手法：提插、捻转
  - 捻转：轻慢短补、快重长泻
  - 提插：紧按慢提补（烧山火）、慢按紧提泻（透天凉）
- 补泻：迎随（顺补逆泻、左补右泻）、摇法（摇大针孔泻）
- 复式手法：白虎摇头、神龙盘转
- 阳数补、阴数泻
- 得气过程：催气、候气、行气、守气、得气
- 补泻要素：呼吸、捻转、徐急、提插、迎随、闭压
- 平针补泻：得气后均匀提插捻转

**烧山火 / 透天凉**

```
烧山火：轻提重压 9 次（补，温热）
透天凉：深刺重提 6 次（泻，清凉）
```

## 7.8 灸法

- 灸材：精艾、粗艾、陈艾
- 隔物：独头蒜、生姜、凡士林

- 保健例：足三里灸 30 分钟，连续七天
- 适应症：寒邪为主
- 灯火灸：灯心草淬烫
- 外治：药物贴敷、膏药
